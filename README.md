# DrawY

AI 创作可以探索和修改的图。界面按绘图工具的样子做，而不是聊天机器人，像一张制图桌：偏冷的浅灰是桌面，上面摆着一张张白纸（画布、画室、设置页，首页的每件作品也是一张纸），没有暖色调的米色底、衬线标题、毛玻璃、胶囊形按钮和加载时的上浮动画；文字和主要按钮是蓝黑的墨色，选中、焦点、链接和正在进行的事用蓝铅笔的蓝，完成的版本盖一枚写着版本号的朱红小印（首页封面的角上、作品页的标题牌、画室和版本面板里都是它，新版本产生时会“盖”一下），灯笼标志也是这个红；字母和数字用工程制图一脉的 Sofia Sans，中文用系统黑体；还没画出来的图片和截图用铅笔排线代替，图片像相纸一样从灰到彩显影。少用文字说明、多用图标，界面文字尽量不提“AI”。界面支持中文与英文，在登录页或账户菜单里切换，选择保存在浏览器里。首页像绘图工具的文件页，整页不滚动：上面是作品（按更新时间排，窗口放得下几行就显示几行，带作者最近一次端详的截图、版次印和状态，点一下打开；放不下的点“查看全部”在左侧栏里看），底部紧贴输入框的一行是“新建空白画布”和三个可以直接发出的示例；左侧栏是首页、新建空白画布、素材库和全部作品（可重命名，用户起的标题之后不会被作者改掉；删除后几秒内可撤销），每个作品标题下有一行状态：正在画、等你回答、上次没有画完、已停止，或当前是第几版和更新时间。账户菜单里是设置、运行记录（只对管理模型的角色显示）和语言。绘图页只有四块：左侧栏、画布左上角的标题牌（作品标题、场景路径和当前版本的印，点印打开版本面板）、中间的画布，以及右侧可折叠的工具栏（撤销、重做、手动编辑、画室、版本、导出与分享）。输入框始终在页面下方（首页也一样），支持中文输入法连续组词；确认候选字的回车不发送，正常回车发送、Shift+Enter 换行。档位选择和剩余提问次数排在它的右下方；发出请求后画室自动打开，输入框收起成页面下方的一条：五小格进度（构思、定内容、备素材、起稿、检查）和当前阶段名，画室关着时还有作者此刻在想或在做的事和已用时间，最后是停止按钮；画布还空着时，中间贴着一张便签，先抄着请求原话和作者正在想的事（随思考更新，带闪烁的光标），定下内容后换成主题、想过的几种画法、选定的想法、受众和画风，生成的图片在便签下面一张张显影，第一笔落下时便签退场；作者提问时展开用来回答，运行结束后恢复原样（窄屏上画室不自动打开）。画室、版本和编辑面板各有自己的宽度：画室默认较宽，版本面板默认较窄，编辑面板居中，拖动面板左边缘调整、双击恢复默认，宽度记在浏览器里。画室是与作者的对话：每次请求、作者的创作过程和回复按时间排在一起。过程里的每一步按工具各有样子：搜索列出查询词和打开的网页，定下内容的一步写着主题、想过的几种画法和选定的想法，素材按要找的东西排出候选，生成图片排成一组随显影出现，落笔列出这一稿的场景和模块，端详画面附上作者看到的截图；作者的思考按标题一条条出现，连续的合成一行，可展开看推理；中间稿不编号，运行结束处标出成稿是第几版。版本按用户的提问来数：一次请求不管作者中途保存了多少稿只算一版，手动修改要保存后才成为一版，空白画布是第 0 版。版本面板每版一行，写着第几版、时间和当时的请求，新的在上；打开它时画布上的选中会取消；点一行在画布上预览（画布下方提示正在查看第几版，可回到当前或回到这一版），每行的“回到此版”按钮一直可见：回到某一版后作品就是那一版，不另记新版本，它之后的版本从列表里移除，下一次请求或保存的修改接着它编号；回退后的提示条上可以撤销（⌘Z 也行），移除的版本随之回来。预览和回退都原地换上画面，不重播落笔动画。运行标题行写着步数和耗时；有模型管理权限的账号在右侧还有一枚费用按钮（普通用户按提问次数计，不看 token 和费用），点开是这次的用量卡片：上面是费用、token（含缓存命中率）、耗时、搜索和图片几块数字，中间一条按服务分色的费用构成，下面绘制模型、联网搜索、生图各一行，写明用了多少、花了多少钱和占比；卡片写明模型名、思考强度和速度，有失败时多一行“失败与重试”，列出失败次数、耗时、消耗、费用和写坏的工具参数次数（中断的输出按已收到的内容估算，标“约”）；画室顶部一行（同样只对管理模型的账号显示）是整个作品所有请求的累计费用与用量，点开是同样的卡片。回复按 Markdown 排版（加粗、列表、标题、链接），引用的来源在原处显示为小标签并在末尾列出，模型自带的私用区引用记号会被去掉。撤销（⌘Z）按版本回退（有未保存的手动修改时一步步撤销修改），撤销后作品没再变动时可以重做（⇧⌘Z）；重做后再次撤销，退回重做前的版本。导出与分享菜单里有：PNG 原图（截图服务按场景全幅以两倍清晰度渲染）、JPG 小图、复制图片到剪贴板、系统分享（设备支持时；菜单打开就开始准备图片，准备好之前显示加载中）、带标题和署名的社交卡片（方形 1:1、竖版 4:5、横版 16:9，画面先裁掉纸边再放大）、PDF（矢量，一页）和可交互网页（单个 HTML 文件，内含运行时和图片，详情页里的图片也一并内嵌，所有场景都能点进去并有返回按钮；地图数据仍从导出它的站点在线读取）。子场景有自己的地址，浏览器后退回到上一层；一次运行只画了别的场景时，结束后画布自动切到它最后画的那个场景。运行失败时，输入框上方说明作品已保存，并提供“继续完成”；最后一稿还没被作者看过或看出了运行错误时，还会提供恢复到出错前的样子。画布上点选模块，再拖动即可移动，拖空白处平移。能点进子场景或详情的模块，右上角有一枚小箭头标记，鼠标移到模块上时标记展开写明去处（“进入「…」”“查看「…」”）；标记只叠在网页的画布上，不画进作品，作者看到的截图和导出的图片里都没有它。面板展开收起或窗口改变大小时，画面保持中心不动，停下后再平滑地适应一次。

在手机上（窗口窄于 600px，或横着拿的手机），作品页换成为“看和说”做的样子，而不是把电脑版缩小：画布铺满屏幕，顶部浮着返回首页、作品标题（点开可改名、切换场景）、撤销、画室与版本和导出分享，输入框在拇指够得到的底部。宽的图打开时从左边铺满屏幕，字够大能读，右下角的“看全图”随时回到整幅。作者作画时画布不被遮挡，输入框收起成一条进度，点它从底部拉出画室；回复收起后，画室和版本仍在顶栏同一个面板的两个标签里。底部面板按住把手往下拉就关上；浏览器的返回先关上打开的面板或详情页，不会离开作品。点一个版本就收起面板、在画布上原地预览，下方可回到这一版。首页在手机上整页滚动，左侧栏收成左上角的按钮；页面本身不会被输入框或双指放大，菜单总在屏幕里打开。双指缩放和平移，单指拖动画面；点一下选中（能进入子场景的模块点一下就进入，长按只选中不进入），选中后底部出现改字、换图、说说怎么改和删除，选中的部分直接用手指拖到新位置，双击文字就地改字；更精细的排版在电脑上做，或说给作者。横着拿手机时，输入框和面板保持适合阅读的宽度，留出高度给画面。平板和触屏电脑用电脑版页面，画布同样认手指：双指缩放和平移、单指拖动、长按（编辑时弹出原来右键的菜单）、双击改字，手柄、工具盘和连线点按指尖的大小放大，选中元素的四边一直有加号。页面布局可以在账户菜单里手动切换（自动、手机或电脑），选择保存在浏览器里。

作品可以像在主流绘图软件里一样自己改（空白画布也能直接动手画），而且能改的范围和 AI 作者完全相同：作者能写进作品的东西都有手动入口，协议里没有的（比如旋转）手动也做不了。点工具栏的铅笔进入编辑（选中模块后输入框旁的“手动修改”、或在画面上双击文字也能进入），画布就成了一块图板：纸面换成方格纸，上边和左边出现标尺（选中的部分在标尺上投出一段蓝色，指针处有一条细线），左缘竖着一盘工具，右侧换成编辑面板（可以收起，只留画布；窄窗口和竖拿的平板上默认收起）。工具盘里是选择（V）、平移（H）、方框（R）、圆（O）、菱形（D）和更多形状（圆角框、圆柱、文档、气泡）、文字（T）、连线（L）、图片和画法库：拿起形状在画布上拖出大小（或点一下），放下就能直接打字；画法库是一张可搜索的浮层，每个画法都画着自己的样子，点一下放到画面中央，或直接拖到画布上（图片文件也可以拖进来）。画布上：点选、Shift 加选、拖空白处框选；选中的部分像工程图一样标着尺寸（宽在下、高在右，蓝铅笔的尺寸线）；拖动时自动对齐旁边元素的边和中线、保持等距，红色的线标出对齐处和相等的间距（按住 ⌘/Ctrl 不吸附，也可以打开“吸附到方格”），Shift 锁定方向，按住 Alt 拖动是复制一份，编组的元素带着整组走；选框的 8 个手柄缩放，Shift 保持比例、Alt 从中心，多选时整体按比例缩放。选中一个元素后，鼠标靠近哪一边，那边就出现一个加号：点一下延伸出一个相连的同类元素（接着打字就行，新元素在视野外时画面会跟过去），拖到另一个元素上是连线，拖到空白处是在那里新建；连线工具则从一个元素拖到另一个，两端跟着元素的位置自动换边。连线的样子沿用这个场景已有的连线；点一条连线就能单独选中它（悬停时高亮），拖它两端的圆点可以接到别的元素或另一边，Delete 删除、R 调转方向，双击连线给它写字或改字。选中元素或连线时，它上方浮出一条：先是外观（形状、配色、颜色、填充、字号，连线是走线、箭头、虚线……多选时一次改到所有选中的元素上），再是复制、编组、删除、更多，以及“说说怎么改”（把选中的部分交给 AI）；右键菜单带图标，除了剪切、拷贝、粘贴、复制、上下层、编组和删除，还有拷贝外观/粘贴外观（格式刷，跨作品只带目标画法可接受的同名外观属性）和选中同类元素；按住空格拖动平移；双击空白处在那里放一段文字；双击文字或选中后按 Enter 就地改字，双击图片从素材库换一张或上传新图。画布右下角是显示比例（点开可选 100%、看全图、看选中的部分，编辑时还有标尺、对齐和方格的开关与快捷键表）；编辑时输入框收成一行，点进去才展开。面板分“属性”和“图层”：属性页顶部固定着选中内容的名称和操作，往下可改 X/Y/宽/高（可锁比例，左右拖动字母也能调）、对齐、等距分布与等宽等高、多选时共有的外观、画法声明的参数和普通控件（文字框、作品色板加任意色、滑块、开关、选项）、列表和表格这类数据（逐项增删、上下移动）、点击后进入哪个场景或打开哪个详情（可以当场新建子场景或详情），以及连到这个元素的连线（点一行即选中那条连线）；选中连线时，面板列出它两端连着的元素和边（都能直接换，边也可以选“自动”，跟着两个元素的位置走）、方向、文字和样式等参数，以及它用的连线画法；折叠的“画法与代码”里可以换画法、把库画法复制成作品画法、只让这一个元素用一份副本、直接改画法代码和参数，或以 JSON 改整条元素记录。没选中时可以管理当前场景的标题、子场景和交互脚本，改作品的全部样式（线条色、强调色、纸色、线宽、字体等）或一键套用某个风格的配色，编写详情页。图层页按上下层列出元素，点选、双击改名、拖动调整层级，下面再列出这个场景的连线。快捷键（按 ? 打开完整的表）：⌘A 全选、Tab 轮选、⌘C/⌘X/⌘V（可以粘贴到别的场景、作品或标签页，也能直接粘贴图片和文字）、⌘D 复制、⌥⌘C/⌥⌘V 拷贝/粘贴外观、⌘G/⇧⌘G 编组/解组、⌘]/⌘[ 置顶/置底（加 ⌥ 一层）、⌥A/D/W/S/H/V 对齐、⌥⇧H/V 等距分布、方向键微调、Delete 删除、Enter 或 F2 改字、R 调转连线，⌘+/⌘− 缩放、⌘0 回到 100%、⇧1 看全图、⇧2 看选中的部分。每次修改立即显示在画布和面板上（不等服务器回应，只重画改动到的元素）并保存下来（刷新页面不会丢），但还不算一个版本：输入框上方出现一条提示“N 处修改还没保存”，点“保存为第 N 版”（或 ⌘S）才成为新版本，点“放弃修改”回到修改之前（可撤销）；版本面板顶部也有同样的一行。带着未保存的修改向 AI 发请求时，会先问是保存后发送、放弃修改后发送还是取消。修改可以一步步撤销重做；在面板里连续填写时，前一项保存不会打断正在输入的下一项；代码改动保存前检查语法，整个作品按作者写入时同样的规则校验。由画法计算出来、改不到的文字或图片，会把修改要求写进输入框交给 AI。编辑时画上的按钮和入口不响应，以免误触；AI 创作期间不能编辑。下次请 AI 修改时，作者会被告知用户自己改过哪些地方（模块、场景、画法、交互脚本、详情、样式）以及这些地方现在的样子，并保留这些修改；作品没变时只告诉它和上次一样，不再整份重发。同一浏览器的多个标签页共用一条事件连接。画室收起时输入框浮在画布下方，同时显示作者当前的动作、正在挑选的图片、提问（编号列表，点选即答，每题最后一行可以自己写答案）和最后的回复；输入框的回形针可以上传图片或从素材库选择。素材库按所在空间分页显示，不滚动；公共素材、我的素材分栏显示，能看所有素材的角色还多一栏“其他用户”，素材详情写明归属。设置页左侧是偏好，以及按角色权限出现的档位、绘制模型、搜索服务、生图模型、账号、邀请码、角色几栏。用户看不到具体模型：输入框右下方只有一个“档位”选择（管理员配置了多个档位时才出现，例如“快速”“精细”），每个档位里是哪个绘制模型、思考强度、速度、搜索方式和生图模型只有管理员在设置的“档位”页能看到和修改；画室的账单对普通用户也只写档位名。旁边显示剩余提问次数：新账号默认 10 次，每发一次新请求减一（回答 AI 的问题不算），用完后不能再发新请求；管理员在“账号”页给每个账号设置剩余次数，留空为不限。首页输入框可先选画风，图片可拖到页面任意处作为参考。画布负责平移、缩放、选择、移动与调整模块大小，作品保存内容和画法。

流程图、泳道图、架构图、UML 时序图和状态机、ER 图、依赖网、树和思维导图这类“方块加连线”的图不是另一种图种，仍然是一个个可以拖动的模块和连线，只是不用再算坐标：作者只写有哪些方块、谁连着谁，位置由一次“排布”按连线算出来（分层、按图自己说的层、泳道、树或左右展开的思维导图、网格，分组框自动包住成员，过长的流程折成来回几行），方块和字段表按文字定大小，存下来的就是每个模块自己的位置，之后想怎么拖就怎么拖。连线不带坐标，由画面统一走线：直角连线绕开挡在中间的模块，每条线在模块的边上有自己的接口，挤在同一条通道里的线各走各的道，线上的字自己找空位；拖动任何一个模块，相关的线当场重新走，不会错位。箭头的两端可以是 UML 的空心三角、菱形，或 ER 的乌鸦脚；分组框和泳道铺在连线下面，拖动它们会带着上面的模块一起走。手动编辑时，选中几个模块点“按连线整理排布”就是同一种排布。作者每次保存后立刻看到画面和一份量出来的结构问题（哪条线穿过了哪个模块、哪个标签被压住、哪两个方块重叠、哪段字放不下以及需要多大），不用靠看图猜。

作品包含六部分：`brief` 是动笔前定下的创作简报（主题、意图、受众、立意、严谨或个性的语域、风格、美术方向和出场角色），主题与意图的依据必须逐字引用用户说过的话，语域没有说到时由作者按题材选定；立意是作者自己选定的视觉想法：画面先让人看到什么、各部分怎样排布、这种排布说明了什么，它不需要引用，后续修改沿用它，直到请求要的东西它装不下；`drawings` 保存 AI 编写的可复用绘制代码；`scenes` 用模块实例、分组和连线组成场景，连线的两端自己记着连在模块的哪里（不写就跟随模块，始终取相对的两边），场景还带着自己的交互脚本（事件与动画）；`details` 保存独立打开的说明；`materials` 是作品取用的素材快照；`style` 保存共享样式，选定风格时由风格素材填入。实例包含自己的数据、位置、尺寸和导航目标，名字默认就是它的文字。相同画法可用于多个实例；一个值放在哪里决定它影响多大范围：实例的 `data` 只影响这一个，画法的 `defaults` 影响所有用它的实例，`style` 影响整个作品。画法的每个默认值和实例数据都生成编辑面板里的控件，`params` 只在需要时补上名字、范围和选项；库里的画法参数用同一套类型。

作者和手动编辑修改作品用的是同一种写法（`WorkEdit`）：按 ID 只写变化的内容，新 ID 是新增，已有 ID 只改写到的字段；对象按键合并，写 `null` 删除；列表给整个就是替换，给 `{"2": {...}}` 就只改第 2 项；画法代码、脚本和详情页可以整段写，也可以用 `edits` 只替换其中一段；`remove` 连带去掉依赖它的东西（模块的连线和检查、场景的子场景、指向它的跳转）。一次写入要么整个保存成一个版本，要么一点不存。作者的写入被拒时，会一次得到全部问题，每条都指明记录和字段，这次写入会被留住，作者只需发改正的部分（`amend: true`），两次合成一个版本保存。

画法接收 `api`，返回 DOM/SVG 元素。`api.svg/html` 创建局部内容，`api.mermaid` 在浏览器内渲染库里没有的少数记法（流程、架构、状态机、ER 与类图、时序、层级、分层、矩阵、对比这类结构图用库里的结构画法，更好看，跟随作品风格，也能拖），`api.material(id)` 按图片的可见内容放入图像素材（默认立在框的底边，不透明的整幅画边缘羽化入纸），`api.materials` 提供图片的尺寸与语义锚点，`api.draw(id, data)` 调用作品或库里的另一个画法（模块和连线也可以直接以库里画法的 ID 作为 `drawingId`，数据即其参数），`api.effect(id)` 套用质感素材，`api.emit` 触发场景事件。连线的画法还会拿到 `api.route`（画面为它算好的路线：从起点到终点的各个拐点，以及给线上文字找好的位置）和 `api.fromSide/toSide`（两端各连在所属模块的哪条边上），照着画就行，不要自己算绕行。画法代码里字面调用、作为 `drawingId` 或在模块数据里出现的素材 ID 会在保存时自动取入作品，不再被任何代码或数据提到的素材随之移出；库里的画法和质感每次保存都重新取当前版本，所以作者照着素材目录写的参数总能被作品里的代码读懂，没再保存过的作品仍按当时的版本显示。场景的交互脚本通过 `api.on/set/move/openScene/openDetail` 操作实例和导航；异步工作使用 async/await，动画与外部监听通过 `api.animate/cleanup` 管理生命周期。交互状态随场景离开而释放，持久数据通过 `write_work` 原子保存为新版本。连线画在模块之下，但铺在整幅图下面的底图除外，所以箭头能画在一整幅场景插画上。画法由 AI 定义，产品没有预设图种注册表。

素材是让图画得更快更好的现成成分，由独立的 `@drawy/materials` 包和服务管理，有自己的数据库、文件、检索与 HTTP 接口，可以单独运行。素材分四种：`picture` 图像（物件、人物、场景、图标、纹理，记录画面内容、画风、可见内容框、语义锚点和主色）、`drawing` 画法代码（箭头（可直角走线）、引线标注、循环、函数曲线、时间轴、滑块、分段选择，以及结构图：流程与架构的节点（含判断、存储、队列、状态机的起止点等形状）、分组框、字段表（ER 实体与 UML 类）、层级树、分层结构、四象限、对比表、金字塔与漏斗、韦恩图、思维导图、步骤进度、泳道、鱼骨图、时序图、同心圆；图表：柱状图、环形图、仪表盘、关键数字、雷达图、甘特图；对话气泡和清单；还有地图，底图是真实的海岸线、湖泊、带名称的河流、地势晕渲和可选的国界与各国一级行政区（省、州），世界尺度用圆润的 Natural Earth 投影，国家尺度只标主题国家的省名、邻国只标国名，放大到两百公里左右时换成 OpenStreetMap 的真实水系和主干道，再放大到城市时出现街道、公园和铁路并标出主干道名（历史地图可以只关掉现代道路和铁路，精细海岸保留），地点、路线和区域按经纬度放上去，路线可分段着色、调粗细和标方向，真实河流可以按名称突出（整条，或两个地点之间的一段），标签自动避开彼此和路线。这些都是可调参数的绘制与交互函数，颜色和字体取自作品风格，可套风格的质感，每个都带一份示例数据，素材库据此实时画出预览，作者的目录里也附上它）、`effect` 质感（铅笔颗粒、手绘抖边、水彩晕边、排线等 SVG 定义）、`style` 风格（语域、色板与字体 token、手绘规则、配套质感、生图风格句和样张；绘画类风格的首张样张是同一幅海边灯塔小景，并排就能比出画风）。每个素材都有中英名称、别名、分类与说明；检索按字段加权，中文按字对切分并以覆盖率区分 exact/close/related，所选风格优先。地图的地理数据来自 Natural Earth，随策展素材放在 `materials/seed/geo`（总览地形、国界、一级行政区三层，近景另有按 15° 分块的细海岸线，另有三级分块的地势晕渲图；一张图通常只读几百 KB），按图层由素材服务提供，画法用到时才读取；政治图层统一采用一个视角（目前是中国视角），争议边界按该视角的分类画成虚线，不承认的线不画。地区和城市尺度的底图由素材服务按需从 OpenStreetMap 矢量瓦片（默认 OpenFreeMap，可用 `DRAWY_TILES_URL` 更换）取来并缓存在 `data/materials/streets`，所以素材服务需要能访问外网；取不到时地图退回 Natural Earth 底图并在图上注明。素材严格分为公共和私人两类：策展素材和被管理素材的人设为公共的图片是公共素材，所有人可见可用；用户上传或让 AI 生成的图片（带着作者给的名称入库）都是这个用户的私人素材，只有本人和有“查看和使用所有素材”权限的角色能看见、使用。风格样张只取公共图片。作者检索素材时只在公共素材和本人的私人素材里找。策展素材在 `materials/seed`。

作者先理解再动笔，再自己决定怎么画：用户的话决定画什么、给谁看，画面怎么构成由作者负责。它先在 `set_brief` 里写下两三种画法（`ideas`），每种标明种类且互不相同：惯例（这类题材通常画成的样子）、剖面（真实的样子，整体、剖开或切开）、旅程（在空间里走一遍）、变化（同一处随时间）、比例（真实大小的对照）、机理（背后的力或原因在起作用）、类比（结构相同的日常情境）、情景（有人物的一刻）；种类不同，想法才是真正的备选，而不是第一个念头的变体。再从中选出观众最快看懂或最能感受到的一种展开成立意；这几种想法留在这次运行的步骤里，画室和画布上的便签把它们列在选定的想法前面。字段顺序让想法先于立意生成，所以发散真的发生在落笔之前，而不依赖模型的隐式思考；惯例的排法（一排图片加箭头、一堆方框、人物配符号、与请求同名的库画法）只是其中一种，只在题材本来就是那种结构、或用户点名时才选；位置、方向、大小、远近和分组本身要说出真实的关系，发明不能以准确为代价。每次看图按顺序评判：先看所说的是否都对，再看立意是否一眼读得出，最后看工艺，然后找出最弱的地方，观众会注意到就改，立意没出来时重新构图而不是改标注；看完用一句话告诉用户画面现在对立意说出了什么、接下来改什么。请求的词可能指不同的东西时（例如只说“苹果”），用 `ask_user` 一次问清（要表现哪个方面、用什么语域，作者自己定并在进度里说明），选项可附风格样张，用户可以点选、在输入框里补充（随所选选项一起发出）、交给作者决定，或者不画了；`set_brief` 定下后，空白纸上先钉出一张便签写着作者理解的主题、意图、立意、受众和画风，创作过程面板里也记下这条立意；`set_brief` 定下简报，返回风格的 token、手绘规则、质感和出场角色的库内素材（附缩略图）；简报只定图意、事实和要用的素材；作者不事先推算坐标，先大致放好画出来，看图后再小改。主体和场景氛围这类撑起画面的东西，库里没有或风格不符就用 `generate_images` 一次性批量生成，定完简报马上开始，好让图片在布局时显影；标签旁的小装饰优先复用现成素材、简单画或省掉。同批图片可按 key 互相引用以保持同一角色：引用别的图的那张等它显影后才开始，其余并行。之后通过 `write_work → view_canvas → write_work` 绘制与查看。`write_work` 只发改动的部分：模块和连线是两张平铺的表，已有的只改写到的字段（也可以只改数据里的单个值），新的就是新增，其余不动；连线只写两端模块就取相对的两边。保存和截图放在同轮；保存失败时跳过截图，作者先修正保存问题，模型写坏的工具参数也按保存失败告诉它，由它改正后重发。`view_canvas` 默认每个场景一张开场全图，有具体疑问时再加最多三张局部，也可做对象标注和连续点击操作；点击打开的是详情页时不截图，只告诉作者打开了哪一页（详情页是作者自己写的 HTML，由应用统一排版，截下来只是把它的文字还回去），随后关掉它，后面的点击仍在场景里继续；只是打开模块自己跳转目标的检查不测试作者写的任何代码，作者会被提示把它从检查里去掉；几何信息按场景给一次，之后只报告变了的模块及其素材和图片可见内容的位置，并量出最小字号和被裁掉的文字。作者看图前先写下图里关于时间、方向、比例、因果和数字条件的说法（`claims`），截图旁附上它们和简报的意图、立意，要求先逐条核对、再看工艺；有人会据此行动的专业事实（医疗时限、剂量、法律、金融公式、统计）要定向搜索。全图还报告整幅图占开场视图的比例（`figure.viewFilled`），一长条横排只占三成左右，作者据此把构图收进视图；截图服务不可用时重试后结束本次运行；与模型的连接中断、限流或服务端出错时整轮重试，先撤回这一轮已显示的半截内容；完成前必须看过最新版本的所有非空场景，且截图没有运行错误；作者写下结束语、不再调用工具时运行结束，还没达成时会被告知缺什么；最小的字小于 14 像素时提醒一次，让作者放大或说明原因。生图要求透明底的图（物件、人物、图标）若画成了带底色的方块，会自动重画一次，仍然带底就告诉作者；费用包含重画前后已生成的图片，后续重试失败也保留已产生的费用。`capture` 服务只负责浏览器截图，作品没有独立检查模型或评分关卡。

有些服务实现了 Responses 接口却不接受 `tool_choice: allowed_tools` 和 `max_tool_calls`（例如 DeepSeek）：在绘制模型上关闭“支持工具调用限制”（只在 Responses 格式下出现，默认开启），请求就不发送这两项，无论经官方地址还是自定义地址、代理接入；独立搜索仍在 DrawY 执行时按预算拒绝超额调用，工具列表保持不变。

用户只选择管理员配置的档位，强度和速度由档位决定，未指定时使用模型默认值。设置的“档位”页里，每个档位在标题行标出是否为默认、是否可用；展开后先列出让它不能用的原因（供应商没填凭证、模型不能调用工具、模型不支持所选的内置搜索），再是“用户看到”的样子和各项设置：绘制模型和生图模型按供应商分组选择；思考强度和速度第一项是“模型默认”，速度列出连接支持的全部档位，即使模型只开放了一个也能选，选了模型还没开放的速度会自动为该模型开放；底部可以上移、下移（决定输入框旁菜单的顺序）、复制档位和设为默认。绘制模型和生图模型的列表里，每个模型标出被哪些档位用到，并可一键复制。普通用户的素材接口也不会返回生图模型名；有模型管理权限的账号仍可查看素材的完整生成来源。

每次创作任务会固定开始时的绘制模型、强度、速度、搜索、生图及价格设置。回答作者追问时沿用这份设置；在其他作品或标签页切换档位、调整价格，不会改变已开始的任务和它的计费。新的创作请求使用最新设置。

打开作品时先显示画面，运行历史随后加载；历史加载期间可以输入文字，发送和手动编辑在任务状态确定后开放。
