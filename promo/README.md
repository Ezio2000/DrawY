# DrawY 宣传片

这里有两部片子：60 秒的《每个想法，都值得探索》（`src/`）和 55 秒的《请勿触摸》（`touch/`），共用 `src/lib.js` 与 `src/hud.js` 里的缓动、手绘线条、铅笔、光标和字幕。

## 60 秒

一支铅笔的一分钟：脑子里的一团乱线被拉直成输入框，DrawY 先听懂、再一笔一笔起稿，草稿像照片一样显影；它看一眼自己的画再改好；点开地球钻进水循环，再钻进一片叶子；同一个苹果换七种画风；镜头拉远，所有作品铺成一面墙，正中的白纸上，铅笔画出灯笼，火苗亮起——DrawY。

整部片子是一个 HTML 时间线，每一帧都是时间的纯函数 `render(t)`，用 Playwright 逐帧截图；配乐与音效由 `audio/score.py` 用 numpy 从零合成（D 大调、96 BPM，24 小节恰好 60 秒，每个小节线都落在剪辑点上），音效按时间线导出的提示表（`cues.json`）逐个对位。画面中的插画都取自 `materials/seed` 素材库。

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–7 s | 乱线 | 铅笔乱画出一团线，问号冒出，乱线被拉直成首页输入框 |
| 7–10 s | 说给 DrawY 听 | 打字“太阳系是如何运转的？”，发送 |
| 10–17 s | 先听懂，再动笔 | 便签上写下创作简报，铅笔用石墨线起稿、写上名字、排阴影 |
| 17–22 s | 显影 | 图片像照片一样显影，轨道沿路径勾出，名字逐字写出，行星开始公转 |
| 22–27 s | 再看一遍 | 取景框查看画布，圈出“太小了，看不清”，地球放大、添上月球 |
| 27–39 s | 点开 | 点击地球穿过“传送门”进入水循环，再点树进入光合作用，场景路径随之延长 |
| 39–45 s | 十种画风 | 甩镜进入苹果，按拍子换七种画风，再排成一排 |
| 45–50 s | 好奇什么就画什么 | 大模型、心脏、丝绸之路、红楼梦人物关系依次画出 |
| 50–54 s | 一面墙 | 镜头拉远，所有作品铺满一面墙，正中留着一张白纸 |
| 54–60 s | 点灯 | 铅笔画出灯笼，火苗亮起：DrawY · 每个想法，都值得探索 |

## 《请勿触摸》· 55 秒

从“请勿触摸”到“请你动手”。安静的画廊里挂着一幅咖啡静物，下面的牌子写着“请勿触摸”；鼠标双击牌子上的字，选中这四个字改成“请你动手”，禁止的斜杠退去，护栏的绳子从挂钩上落下。镜头推进画里，画变成 DrawY 的画布：点开一颗咖啡豆，走进咖啡的来历（果实、处理、烘焙、冲煮，一颗豆子沿路走进杯里）；选中“烘焙”让 AI 修改，提出新的要求，作者接着画出烘焙曲线和三种烘焙度的风味；导出为可交互网页，整件作品折成一个文件，在手机上打开还能点。最后回到画廊，推近牌子，“请你动手”留在落版上，铅笔画出灯笼、补上句号：DrawY · 请你动手。

| 时间 | 段落 | 画面 |
| --- | --- | --- |
| 0–7.5 s | 请勿触摸 | 画廊、咖啡静物和牌子；双击、选中、改字，斜杠退去，绳子落地 |
| 7.5–12.3 s | 画活了 | 推进画框，画变成画布；点开咖啡豆，穿过它进入下一个场景 |
| 12.3–22.5 s | 咖啡的来历 | 四站的路依次显影，一颗豆子从果实走到冲煮，跳进滤杯 |
| 22.5–27.3 s | 提出新的要求 | 选中“③ 烘焙”，让 AI 修改，输入要求并发送 |
| 27.3–35 s | 展开细节 | 钻进烘焙机，铅笔画出豆温曲线、转黄、一爆和三种烘焙度的风味 |
| 35–45 s | 带走 | 退回来历，导出可交互网页，作品折成文件飞进手机，点开豆子照样能进 |
| 45–55 s | 请你动手 | 回到画廊，推近牌子，落版：灯笼点亮，DrawY · 请你动手。 |

配乐 `audio/touch.py` 同样是 D 大调、96 BPM，22 小节恰好 55 秒；前三小节只有画廊的空气声、远处的脚步和几个八音盒音，改完字、绳子落地的那一拍（7.5 s）乐曲才进来。乐器与 `score.py` 相同。

## 生成

需要 Node、Python 3（numpy、scipy）、ffmpeg 和 Playwright 自带的 Chromium。

一键生成：`promo/build.sh`（帧 → 配乐 → 按 -14 LUFS 线性标准化 → H.264/AAC，BT.709），得到 `out/drawy-60s.mp4`；`promo/build.sh touch` 生成《请勿触摸》，得到 `out/touch/drawy-touch-55s.mp4`。`render.mjs` 用环境变量 `FILM` 选片（`src` 是默认的 60 秒，`touch` 是《请勿触摸》，输出在 `out/touch`）。分步：

```sh
cd promo
npm install                         # 字体：霞鹜文楷、思源宋体/黑体、Instrument Serif、Fraunces
node render.mjs stills 12 24.3 55.5 # 渲染几张静帧到 out/stills
node render.mjs frames 60 4         # 60 fps，4 个页面并行，帧写到 out/frames，提示表写到 out/cues.json
python3 audio/score.py out/cues.json out/score.wav
ffmpeg -framerate 60 -i out/frames/%05d.jpg -i out/score.wav \
  -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p -c:a aac -b:a 256k \
  -af loudnorm=I=-14:TP=-1:LRA=11 -shortest -movflags +faststart out/drawy-60s.mp4
```

`FILM=touch node render.mjs stills 4.7 23.9` 渲染《请勿触摸》的静帧，`python3 -I audio/touch.py out/touch/cues.json out/touch/score.wav` 生成它的配乐。

在浏览器里直接打开 `src/index.html` 或 `touch/index.html`（需从仓库根目录起一个静态服务）会实时播放；`?t=秒` 停在某一帧，`?from=秒` 从某处开始播放。

## 文件

- `src/main.js` 时间线：开场乱线、输入框、各镜头的摄像机、俯冲转场、作品墙与灯笼落版
- `src/drawings.js` 片中的作品，每幅都按自己的本地时间画出来，也能以完成状态再画一次放上墙
- `src/hud.js` 屏幕层：铅笔、光标、字幕、取景框、品牌的灯笼与火花
- `src/lib.js` 缓动、手绘线条、自画的路径与文字、显影、提示表
- `audio/score.py` 配乐与音效
- `touch/main.js` 《请勿触摸》的时间线：画廊、牌子上的改字、护栏、摄像机与俯冲、选中与提问、导出与手机、落版
- `touch/art.js` 片中的三个场景：咖啡静物、咖啡的来历、烘焙曲线，各按自己的本地时间画出来，在墙上、画布和手机里各有一份
- `touch/touch.css` 这部片子新加的样式：画廊、牌子、工具条、导出菜单、文件卡片、手机、落版
- `audio/touch.py` 《请勿触摸》的配乐与音效
