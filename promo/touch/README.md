# 《请勿触摸》· DrawY 55 秒宣传片

从“请勿触摸”，到“请你动手”。

深夜的美术馆里，聚光灯下挂着一幅水彩咖啡静物，画下的铜牌写着“请勿触摸”。光标从暗处出现，双击铜牌，选中这四个字，改成“请你动手”；英文跟着翻成 HANDS ON, PLEASE，灯光一暖，画里的咖啡冒出热气，越过画框飘进展厅。画中一颗咖啡豆沿着豆缝裂开，里面是一幅长卷：果实、处理、烘焙、冲煮，一颗豆子从枝头落下，洗去果皮，晒干，进烘焙机，出来时已是深褐色，最后落进滤杯。长卷收成全景，选中“烘焙”，输入要求，烘焙机的炉门打开，一页细节从里面展开：豆温曲线、九颗由青到黑的豆子、一爆，以及浅烘、中烘、深烘的风味。整幅长卷卷起，系上红绳和“咖啡的来历.html”的签，落进手机；在手机上点开豆子，照样能进。镜头推进手机，接回美术馆的那幅画，两旁的画也一盏盏亮起来。最后推近铜牌，“请你动手”留在纸上，一滴咖啡落下，干成句号：DrawY · 请你动手。

## 怎么做的

整部片子是一个 HTML 时间线，每一帧都是时间的纯函数 `render(t)`，用 Playwright 逐帧截图。片中所有画面都是加载时用代码在 canvas 上画出来的，不用任何图片素材：

- 水彩是把一个多边形一次次做中点扰动，再用很淡的颜色叠几十层，所以边缘柔软不齐、颜料积在边上；需要湿画的地方再加一点晕开。墨线是按笔压变化宽度的填充轮廓。每个物体先画在自己的纸上，铺下去之前把它轮廓里的纸恢复干净，所以前面的东西能挡住后面的。
- 长卷分远山、中景、地面和镜头前的虚化物几层，横移时速度不同，拉远看全景时正好对齐。
- 配乐 `audio/score.py` 是用 numpy 合成的爵士三重奏：带琴弦刚度和制音器的钢琴、Karplus-Strong 拨弦的低音提琴、鼓刷与叮叮镲。F 大调、96 BPM、摇摆八分音符，22 小节恰好 55 秒；音效按时间线导出的提示表（`cues.json`）对位。

这部片子不引用仓库里的任何现有素材或代码，只有“DrawY”这个名字和片名。

## 生成

需要 Node、Python 3（numpy、scipy）、ffmpeg 和 Playwright 自带的 Chromium。

```sh
cd promo/touch
npm install                              # 字体：思源宋体/黑体、马善政、IBM Plex Mono、Bricolage Grotesque、Young Serif
./build.sh                               # 帧 → 配乐 → -14 LUFS → out/drawy-touch-55s.mp4
node render.mjs stills 4.8 25.6 54.5     # 几张静帧到 out/stills
node render.mjs lab cover jo r5          # 单独看一幅画：静物、长卷全景、烘焙细节
```

`src/index.html` 在浏览器里（从本目录起一个静态服务）会实时播放；`?t=秒` 停在某一帧。

## 文件

- `src/main.js` 时间线：美术馆、铜牌上的改字、摄像机、豆缝、选中与提问、卷起与手机、落版
- `src/paint.js` 水彩、墨线与纸
- `src/art.js` 豆子、樱桃、叶子、咖啡渍、印章、静物与两旁的小画
- `src/journey.js` 咖啡的来历：长卷的分层、豆子的路线
- `src/roast.js` 烘焙的细节页
- `src/core.js` 缓动、随机、噪声、摄像机、提示表
- `audio/score.py` 配乐与音效
